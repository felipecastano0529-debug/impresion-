# Pida Pues Printer — Releases

Repositorio público de distribución del plugin de impresión Pida Pues Printer.

Los binarios `.dmg` (macOS) y `.exe` (Windows) se publican aquí automáticamente
desde el workflow de GitHub Actions del proyecto principal.

## Descarga
La forma fácil: ve a [/app → App impresora](https://www.pidapues.com/app) en tu
panel y toca el botón de descarga. La página apunta siempre a la última versión.

## Instalación
- **macOS**: doble click en el `.dmg` → arrastra a Aplicaciones. Primera vez,
  click derecho → Abrir → Abrir igual (la app no está firmada con cert de Apple).
- **Windows**: ejecuta el `.exe` → si SmartScreen avisa, "Más información →
  Ejecutar de todas formas".
